# Paint Robot

A Python-based research and implementation project for paint robot control and optimization.

## Project Structure

- **main.ipynb** - Research notebook for experimentation and analysis
- **paintbot/** - Core Python package containing backend functionality
- **docs/** - Sphinx documentation

## Getting Started

### Prerequisites

- Python 3.8+
- pip or conda

### Installation

```bash
# Install the package in development mode
pip install -e .
```

### Development

To run the research notebook:

```bash
jupyter notebook main.ipynb
```

### Documentation

To build the Sphinx documentation:

```bash
cd docs
make html
```

Documentation will be available in `docs/_build/html/`
